    -> Functional Programming 

        -> In computer science, functional programming is a programming paradigm 
        where programs are constructed by applying and composing "functions"


    -> Functions

        -> In Python, a function is a named, "reusable block of code" that performs 
        a specific task, takes input (arguments), processes data, 
        and can return an output.

        -> Functions can break down complex problems into smaller and
        simpler manageable sub tasks for promoting code modularity. 

        -> Once defined a function, it can be "called multiple times", so that 
        we can achieve code reusability.


    -> Functions are defined using "def" keyword, followed by function name,
    parenthesis(which may contain parameters), and a colon:
    the code within the function is indented 

        -> Syntax

            def function_name():
                statements

            def function_name(parameters):
                statements

        -> NOTE: calling function is must

            function_name()
            function_name(parameters)

    
        -> Python functions can be defined to accept "parameters" 
        which can act as placeholders for values that will be 
        passed into function when called. 
        
            -> Values passed to the function we call them as "arguments"

            -> We use parameters to make functions dynamic in nature


    -> Based on arguments passed to a function, we got five Types

        -> Positional Arguments

        -> Keyword Arguments

        -> Default Arguments

        -> Arbitrary Positional Arguments

        -> Arbitrary Keyword Arguments


    -> Positional Arguments

        -> In Python, positional arguments are values passed to a function during 
        its call, where the assignment of these values to the function's parameters 
        is determined solely by their "order" (position) in the argument list. 

        -> The first argument in the function call is assigned to the first parameter 
        in the function definition, the second to the second, and so on. 

        -> Order Matters: If the order is incorrect, the function will receive the wrong values 
        for its intended parameters, potentially leading to errors or unexpected behavior.


    -> Keyword Arguments

         -> In Python, keyword arguments are a way to pass values to a function by explicitly 
        "naming the parameters" they correspond to, rather than relying on their position 
        in the argument list. 

        -> This offers advantages, primarily in terms of code readability and flexibility.


    -> Default Arguments

        -> In Python, default arguments allow you to define a function parameter 
        with a "pre-assigned" value i.e default value 

        -> If a caller does not provide an argument for that parameter during a function call, 
        the default value is automatically used. 
        If an argument is provided, it overrides the default.

        -> Placement Requirement: Default arguments must always be placed after 
        any non-default arguments in the function definition. 
        Attempting to place a non-default argument after a 
        default argument will result in a SyntaxError.


    -> Arbitrary Positional Arguments

        -> Arbitrary means unknown or random 

        -> In Python, arbitrary positional arguments allow a function to accept 
        a unknown number of Positional arguments. 
        This is achieved by placing an asterisk (*) before a parameter name 
        in the function definition. 

        -> This parameter will then collect all the positional arguments 
        passed to the function into a tuple. 

    
    -> Arbitrary Keyword Arguments

        -> Arbitrary means unknown or random 

        -> In Python, arbitrary keyword arguments allow a function to accept 
        a unknown number of Keyword arguments. 
        This is achieved by placing an asterisk (**) before a parameter name 
        in the function definition. 

        -> This parameter will then collect all the Keyword arguments 
        passed to the function into a Dictionary, 
        where names will be keys and value is value

    -> return keyword 

        -> In Python, the "return" keyword is used within a function 
        to send a value back to the part of the code that called the function.

            -> Task -> O/P -> I/P Another Task (Fails)

            -> Task -> return O/P -> I/P Another Task (Succeed) 

        -> When working with function composition (function calling another function), 
        return will be helpful

        -> NOTE: when you don't use a return, by default a function returns None 

        ->  If you use return, make sure it's the last part of statement to be executed

        -> If you have multiple return statements, first return will be considered

        -> If multiple returns are present, and used with conditionals, 
        you can control the flow 

    
    -> Scopes In Functions 

        -> Scope: Inside the function code blocks, where you can access variable depends on Scope

            -> Local Scope

            -> Global Scope

        
        -> Local Scope

            -> A local variable declared "inside the function" 
            -> It's lifetime exists only within the function
            -> We cannot use them outside the function   
            -> NOTE: Parameters we are passing to the functions, are also local variables  

        -> Global Scope

            -> A Global variable declared outside the function 
            
            -> it's lifetime exists within the function as well as outside function 

            -> As global variables can be accessed inside the functions, there can be
            name conflicts, in this scenario the preference is given to local variables 

                -> NOTE: To Access Global Variable in above scenario, use globals()

            -> If you want global variables to be changed inside the function, we cannot 
            do that directly 

                -> NOTE: To change Global Variable inside function, use global keyword

    -> Lambda Functions 

        -> A lambda function in Python is a small, anonymous function 
        defined with the "lambda" keyword.

        -> Unlike Standard Functions(block of code), Lambda functions are 
        restricted to single line expression 

        -> Unlike Standard Functions, Lambda functions automatically returned(Implicit) 
        without using a return statement

        -> Lambda Functions are often used for "short, one-time operations" where 
        a full function definition would be unnecessarily verbose.

        -> Using Lambda Functions we can write "one liner functions" called "IILE" 
        Immediately Invoked Lambda Expression

        -> Syntax

            lambda arguments:expression

        -> NOTE: Generally lambda functions will be "attached" with "Higher Order Functions"

    -> Higher Order Functions 

        -> The goal of Higher Order Functions is to "perform operations on Iterables" 

        -> Concise Code, without writing lengthy code with loops and conditionals

            -> NOTE: Remember Imperative vs Declarative Style (How To Do vs What To Do)


        -> map()

            -> map() function applies a given function(preferably lambda function) 
            to each item in an Iterable/Collection and returns an Iterator containing results.

            -> NOTE: map() function provide a Concise way to perform "Data Transformations" 
            on collections without writing loops / lengthy code. 

            -> Syntax 

                map(function,Iterable) 

            -> NOTE: Just Like Using For Loop With Standard Functions 

            -> NOTE: Used Widely In Data Transformations 



    -> filter()

        -> filter() function applies a given function(preferably lambda function)
        to each item in an Iterable and returns an Iterator Containing Results. 

        -> NOTE: filter() function provides a Concise Way To Perform 
        "Data Extractions" Without Using Length Loops With Conditionals. 

        -> It is a powerful tool for "selectively extracting data" 
        based on a "given condition".

        -> Syntax 

            filter(function,Iterable)

        -> NOTE: Just Like Using For Loop and Conditionals With Standard Functions  

        -> NOTE: Used Widely In Data Extractions 

    
        -> map() - Data Transformations

        -> filter() - Data Extractions
