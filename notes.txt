Class - 9
==========

    -> Dictionaries 

        -> Dictionary is a data structure which allows you to store multiple "key values"
        in a single variable, each value is separated with ,

        -> Dictionaries are represented using { } or using "dict" class

        -> Dictionaries Store Key Value Pairs 

            -> key:value

            -> {key1:value1,key2:value2,key3:value3}

            -> https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQSib6nLERnnqTxvDUQa5l1ykY9tHPi8c9mWOQV2nwnRl0vXzj01vhWtr-o&s=10

        -> Dictionaries Allows Duplicates(*)

            -> Values Can Be Duplicated 

            -> Keys Should Be Unique, If we add duplicates, latest will override the old key 

            -> Keys Should Be Immutable Object Only, Values Can Be Any Objects

    -> Sets 

        -> Set is a data structure which allows you to store multiple values
        in a single variable, each value is separated with ,

        -> Sets are represented using { } or using "set" class

            -> {key1:value1,key2:value2,key3:value3} - Dictionary

            -> {value1,value2,value3} - Set 

        -> Sets Doesn't Support Indexing & Slicing 

        -> NOTE: To Easily remember sets (UUU)

            -> U - Unique Data 

            -> U - Unordered Data 

            -> U - Unindexed Data 

        -> NOTE: With sets we can do Mathematical set operations (class X - XI)

            -> https://i0.wp.com/mathematicalmysteries.org/wp-content/uploads/2023/08/e-math-set-notation-venn-diagram.jpg?fit=800%2C539&ssl=1

        -> Sets Are Mutable In Nature
